# Qurani Piroz — ساخت خودکار فایل APK آفلاین با GitHub

## مراحل ساخت APK (حتی با گوشی):
1. در سایت [GitHub](https://github.com) یک مخزن (Repository) جدید بسازید.
2. تمام فایل‌ها و پوشه‌های داخل این بسته (به‌خصوص پوشه `.github`، `www`، `assets`، `package.json` و `capacitor.config.json`) را در مخزن آپلود کنید.
3. وارد تب **Actions** در بالای مخزن شوید؛ ساخت APK به‌صورت خودکار شروع می‌شود (حدود ۲ تا ۳ دقیقه طول می‌کشد).
4. پس از سبز شدن تیک اجرا، روی آن کلیک کنید و از بخش **Artifacts** فایل **Qurani-Piroz-APK** را دانلود و روی گوشی نصب کنید.
